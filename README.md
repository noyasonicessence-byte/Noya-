# 诺雅 · 歌曲发音标注 / Noya Pronunciation Studio

一个用于「边讲边展示」英文歌曲发音（连读）的单页网站。粘贴歌词，逐字点击标注四种连读现象，进入演示模式全屏展示，或导出图片。

## 使用方法

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

1. **粘贴歌词**：左边填英文歌词（每行一句），右边可填你的中文可演唱版（按行与英文对应，可留空）。
2. **生成标注区**：点「生成标注区」，歌词会以逐字可点击的形式显示在米色卡片上。
3. **选工具标注**：在左侧工具栏选一种工具，然后点字母标注。
4. **载入音频**：点「载入音频」选择本地音频文件，下方出现播放器（播放 / 暂停 / 拖动进度）。
5. **演示模式**：点「演示模式」进入全屏干净展示（`Esc` 退出），适合讲课或截图。
6. **导出 PNG**：一键导出标注卡片图片；若浏览器导出失败，可直接截图（Win：`Win+Shift+S`；Mac：`Cmd+Shift+4`）。

内容会自动保存在浏览器本地（localStorage），刷新不丢失。

## 两个视图：标注 / 练习页

顶部「标注 ↔ 练习页」切换：

- **标注**：逐字标四种连读，配卡拉OK跟唱高亮（见下）。
- **练习页**：仿「一句一练」形式，每句一张卡片——序号、英文、中文、单句播放、循环、以及逐句校时（`此处` 设为当前音频位置，`−.5 / −.1 / +.1 / +.5` 微调 0.1~0.5 秒）。开「标关键词」后点词可高亮重点词。练习页用的是逐行时间，和「打轴·逐行」共用同一份时间轴。

## 卡拉OK逐字同步（打轴）

工具无法自动听音频生成时间轴，采用**手动打轴**（准、可控、通用）：

1. **载入音频**（本地文件，不上传网络）。
2. 选粒度：**逐词** 或 **逐行**。
3. 点 **开始打轴**：音频从头播放，在每个词/每行被唱到的**瞬间**按 `空格`（或点「打点」）打一下点，光标自动跳到下一个。按 `Backspace`（或「退一步」）纠正。
4. 点 **结束打轴**保存。
5. 点 **跟唱播放**：音频播放时，当前正在唱的字会被金色高亮「擦过」，并自动滚动到当前行——适合边讲边展示。

时间轴随工程一起存在浏览器本地。**导出工程 / 导入工程**（JSON）可保存或换设备继续。

> 版权提示：工具本身不内置任何歌词与音频，请自备你有权使用的素材，运行时粘贴 / 载入。

## 四种连读标注

| 工具 | 含义 | 呈现 |
| --- | --- | --- |
| **连读** ⌒ | 前后音相连（linking） | 先点起点字母，再点终点字母，画一条弧线相连；再点同一对可删除 |
| **划掉** | 吞音 / 失爆（dropped） | 点字母 → 变灰并加斜线 |
| **弱读** ə | 弱读 / 央元音（reduced） | 点字母 → 变绿 |
| **增音** ʷ / ʲ | 两元音之间加滑音 w / y | 点字母 → 其后插入蓝色小 w 或 y；点小字母可删除 |

其它：**撤销**（`Ctrl/Cmd+Z`）、**清标注**（清除当前全部标注）。连读弧线在同一行内相连。
