# 诺雅 · 七维教学工作台 / Noya Expression Studio

一个专注**语言教学内容本身**的标注与设计工具。拍摄交给相机/直播，剪辑/背景/画面交给剪映——本工具只做「逐句拆解 + 七维教学设计」，输出可用于课程 / 短视频 / 直播 / 教案 / 跟读练习的结构化内容。

直接用浏览器打开 `index.html` 即可，无需安装，内容自动存在浏览器本地。

## 界面结构（三栏）

- **顶部**：标题、`原文 / 编辑`（粘贴英文原文 + 可选中文参考，点「生成逐句」）、导出/导入教学工程。
- **左栏**：英文逐句列表。每句下方有 **7 个维度小圆点**，点亮表示该句启用了哪些教学维度；点圆点可快速跳到该维度。
- **中栏**：当前选中句子 + **语感发音可视化标注**。
- **右栏**：七维教学面板（Tab 切换），编辑当前句子的教学内容。

七个维度**不是必填的七步**。每句话自由选择最值得教的一个或多个维度。

## Noya 七维教学法

1. **语感 Sound** — 逐字发音标注（最重要、最可视化）：连读弧线、弱读、失爆/吞音、弹舌 t、加音 w/y、重音、停顿/意群、词注（词上中文 + 词下音标）。在右侧「语感」选工具，点中间句子的字母。
2. **思维 Thinking** — 英语为什么这样表达？母语者如何组织意义、选择表达（重点不是语法）。
3. **双语映射 Bilingual Mapping** — 不是逐词翻译。把一个英文意义块 ↕ 一个自然中文意义块对应（如 *You can count on me.* ↕ 有我呢）。
4. **实时共振 Live Resonance** — 这句话与当下生活、经验、社会、哲学的连接，用于生成延展讲解。
5. **画面觉醒 Visual Awakening** — 听到/说出这句时脑中应出现的动态画面（只写描述，供剪辑找素材）。
6. **电影记忆 Cinematic Memory** — 把语言放进有角色/情绪/前因后果的场景：人物、场景、前因、此刻、后续（可选来源）。
7. **Flow** — 识别句子里连续的意义运动，把它切成若干意义波段（chunk），感受如何自然向前推进。

## 数据

- 每句的发音标注与七维内容都保存在浏览器本地。
- `导出教学` 生成结构化 JSON（可存档、换设备、后续生成讲解/教案的原料）；`导入` 恢复。
