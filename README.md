# 诺雅 · 歌曲发音标注 / Noya Pronunciation Studio

一个用于「边讲边展示」英文歌曲发音（连读）的单页网站。粘贴歌词，逐字点击标注四种连读现象，进入演示模式全屏展示，或导出图片。

## 使用方法

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

1. **粘贴歌词**：左边填英文歌词（每行一句），右边可填你的中文可演唱版（按行与英文对应，可留空）。
2. **生成标注区**：点「生成标注区」，歌词会以逐字可点击的形式显示在米色卡片上。
3. **选工具标注**：在左侧工具栏选一种工具，然后点字母标注。
4. **载入音频**：点「载入音频」选择本地音频文件，下方出现播放器（播放 / 暂停 / 拖动进度）。
5. **演示模式**：点「演示模式」进入全屏干净展示（`Esc` 退出），适合讲课或截图。
6. **导出 PNG**：一键导出标注卡片图片；若浏览器导出失败，可直接截图（Win：`Win+Shift+S`；Mac：`Cmd+Shift+4`）。

内容会自动保存在浏览器本地（localStorage），刷新不丢失。

## 两个视图：标注 / 练习页

顶部「标注 ↔ 练习页」切换：

- **标注**：逐字标四种连读，配卡拉OK跟唱高亮（见下）。
- **练习页**：仿「一句一练」形式，每句一张卡片——序号、英文、中文、单句播放、循环、以及逐句校时（`此处` 设为当前音频位置，`−.5 / −.1 / +.1 / +.5` 微调 0.1~0.5 秒）。标注视图里做的**连读弧线与颜色会一起显示在卡片上**。开「标关键词」后点词可高亮重点词。练习页用的是逐行时间，和「打轴·逐行」共用同一份时间轴。

  **更省事的校时——逐句打点**：练习页顶部点 `▶ 逐句打点`，音频从头播放，在每句开头按 `空格`（或点该句卡片）打一下点，自动跳下一句，一遍过就设好全部时间；`Backspace` 纠正。旁边的 `0.5× / 0.75× / 1×` 变速，既方便打点也方便跟读。

  **导出长图**：练习页下点「导出 PNG」，会把整列卡片导成一张竖向长图（自动去掉按钮和序号，只留英文/中文/标注），适合发抖音。标注视图下导出的是单张标注卡片。

## 卡拉OK逐字同步（打轴）

工具无法自动听音频生成时间轴，采用**手动打轴**（准、可控、通用）：

1. **载入音频**（本地文件，不上传网络）。
2. 选粒度：**逐词** 或 **逐行**。
3. 点 **开始打轴**：音频从头播放，在每个词/每行被唱到的**瞬间**按 `空格`（或点「打点」）打一下点，光标自动跳到下一个。按 `Backspace`（或「退一步」）纠正。
4. 点 **结束打轴**保存。
5. 点 **跟唱播放**：音频播放时，当前正在唱的字会被金色高亮「擦过」，并自动滚动到当前行——适合边讲边展示。

时间轴随工程一起存在浏览器本地。**导出工程 / 导入工程**（JSON）可保存或换设备继续。

> 版权提示：工具本身不内置任何歌词与音频，请自备你有权使用的素材，运行时粘贴 / 载入。

## 意境背景 · 成片导出（今日收获卡）

每首歌可配一张贴合意境的背景图，把**准确的歌词 + 连读标注**叠在上面导出成片（AI 直接烤在图里的文字常拼错，用这个能保证字对、标注对）：

1. **上传背景图**（你的氛围图，如复古/胶片/星空）→ 自动切到「意境」主题，歌词卡叠在图上。
2. **纸卡 / 意境** 切换：纸卡=米色卡片；意境=叠在背景图上（带柔化蒙版保证可读）。
3. **深字 / 浅字**：背景亮用深字，背景暗用浅字。
4. **成片比例**：竖 9:16（抖音）/ 方 1:1 / 横 16:9，点「成片导出」出图——顶部歌名、中间标注内容、底部图例 +「诺雅·Noya」水印。

背景图与主题会随工程保存在本地（图太大时仅当前会话有效，需重新上传）。

## 弹舌 t · 聚焦 · 口型图 · 竖屏成片

- **弹舌 t（Flap t）**：工具栏「弹舌t」，点字母 → 变红并标 `[d]`（water / better 那种美式弹舌音）。
- **单词聚焦放大**：演示模式下点任意单词 → 该词放大聚光、其余变淡；再点取消，点空白也取消。适合特写讲某个词。
- **发音口型图库**：顶部「口型图」打开浮窗，内置 `θ/ð`、`t/d`、`n`、`l`、`r` 的舌位剖面图（红点=触碰点，绿箭头=鼻腔气流），配中文要点。讲到某音一键调出，浮窗在演示模式下也保留。
- **竖屏成片（9:16）**：填「歌曲标题」后点「竖屏成片」，导出 1080×1920 竖版海报——顶部标题、中间标注内容、底部图例 + 「诺雅·Noya」水印，直接发抖音。

## 词注 · 重音 · 录制辅助

- **词注（A文）**：选「词注」工具点单词 → 弹出小框，可填 **词上中文**（如"抱在怀里"）和 **词下音标**（如 `/tə/`、`/jər/`），保存后显示在词的上/下方。两个视图和导出图都会带上。
- **重音（•）**：选「重音」工具点单词 → 词上方出现金色拍点；「跟唱播放」时当前词的拍点会随音频跳动（歌曲/rap 的节奏感）。
- **逐步显现**：点「逐步显现」进入演示并只显示第一句，用演示条上的 `‹ ›`（或键盘 `← →`／`空格`）一句句点亮，边讲边显现，录课不用后期剪。
- **激光笔**：演示条上「激光笔」（或按 `L`）开启，鼠标变成发光红点，讲到哪指到哪。
- 演示模式右上角有一条工具条：`‹`上一句 `›`下一句 `激光笔` `退出`；按 `Esc` 也可退出。

## 四种连读标注

| 工具 | 含义 | 呈现 |
| --- | --- | --- |
| **连读** ⌒ | 前后音相连（linking） | 先点起点字母，再点终点字母，画一条弧线相连；再点同一对可删除 |
| **划掉** | 吞音 / 失爆（dropped） | 点字母 → 变灰并加斜线 |
| **弱读** ə | 弱读 / 央元音（reduced） | 点字母 → 变绿 |
| **增音** ʷ / ʲ | 两元音之间加滑音 w / y | 点字母 → 其后插入蓝色小 w 或 y；点小字母可删除 |

其它：**撤销**（`Ctrl/Cmd+Z`）、**清标注**（清除当前全部标注）。连读弧线在同一行内相连。
